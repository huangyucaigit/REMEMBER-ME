# 法规依据与权利边界

> 目标：把“完整订购关系”拆成多个法规共同支撑的证据环节，同时明确消费者合理请求的边界。

## 一、核心法规矩阵

| 依据 | 核心内容 | 对本案意义 |
|---|---|---|
| 《电信服务规范》信息产业部令第36号，第6.2项 | 任何有偿信息服务应事先征得用户同意 | **基础规则，非常强** |
| 信部电〔2004〕136号 | 包月/订阅短信必须确认；保存记录；提供SP/收费清单；争议共同处理 | **短信确认场景的交叉依据** |
| 信部电〔2005〕82号 | 代理收费前，被代理方应提供资料证明用户“知情、自愿”；并明确告知收费方式、标准、周期等 | **代收费场景极关键** |
| 信部清〔2006〕574号第5项 | 包月/订阅业务必须事先确认；未经确认订制不成立、不得收费 | **直接核心** |
| 信部清〔2006〕574号第9项 | 保存“申请订购—请求确认—用户确认反馈”及时间、号码/接入代码、具体信息内容 | **完整订购证据链核心** |
| 信部清〔2006〕574号第10项 | 未按规定提醒/确认或订购关系缺失、不完整时处理争议费用 | **后果核心** |
| 《消费者权益保护法》 | 知情权、自主选择权、真实全面信息、真实经营主体 | **上位法支持** |
| 《消费者权益保护法实施条例》 | 服务内容、价格等应显著真实；自动续费/自动展期有提醒义务 | **连续收费与经营主体披露补强** |
| 《个人信息保护法》第45、50条 | 查阅、复制本人个人信息；拒绝请求应说明理由 | **本人订购/确认/订单/计费信息查阅依据** |
| 《电信业务经营许可管理办法》第20、22、48条 | SP接入资质及移动对内容、收费、合作行为的管理责任 | **SP资质与运营商管理责任** |

## 二、《电信服务规范》第6.2项

核心原则：

> 信息服务业务经营者向用户提供任何有偿信息服务，应事先征得用户同意。

对本案的直接问题：
- 收费之前，消费者是否真实同意；
- “已成功开通”结果短信不能替代事前同意；
- 若主张验证码即同意，应证明验证码所对应的具体收费业务及告知内容。

官方来源可从工信部/各省通信管理局公开的《电信服务规范》查阅。

## 三、信部电〔2004〕136号

适用时应注意其主要针对短信息服务场景。

可作为本案短信确认环节的交叉依据：
- 包月/订阅类短信服务需事先确认；
- 保存短信发送/接收时间及号码/代码；
- 代收费账单应显示SP等信息；
- 对信息费争议，双方实行首问负责，不得互相推诿。

**使用边界：**
“云灵猴AI编程”本身未必属于短信服务，因此不机械主张整份文件全部适用；重点用于核查“短信确认”环节。

## 四、信部电〔2005〕82号——代理收费关键规则

文件主题：**规范增值电信业务代理收费行为**。

### 第4项：收费前的“知情、自愿”证明
在代理方向用户代理收取费用前，被代理方应提供相关资料，证明用户是在**知情、自愿**情况下使用该业务。

对本案形成一个非常关键的问题：

> **杭州漫卷诗在浙江移动第一次代收20元之前，向浙江移动提供了什么资料，用来证明消费者知情、自愿使用“云灵猴AI编程”？**

这不是要求运营商开放整个后台，而是要求其说明：
- 是否存在该证明；
- 证明资料的类型；
- 形成时间；
- 能证明什么具体事实。

### 第6项：收费方式、标准、周期等应告知
被代理方在用户申请使用业务时，应通过网站、协议、短信等方式明确告知：
- 代理收费方式；
- 收费标准；
- 收费周期；
- 客服电话等。

因此应核查“快捷换图标大师”的广告/落地页/订购页或其他告知载体。

### 第8项：争议费用处理
对已经付费、发生代理收费争议的用户，在双方无法在规定期限内提供证据证明收费无差错时，存在先行暂退费机制。

**意义：**
退款/充值处理不等于已经证明订购合法，也不等于违法自认；“费用处理”和“完整订购证据核查”是两件事。

官方来源：各省通信管理局公开的信部电〔2005〕82号文本。

## 五、信部清〔2006〕574号

### 第5项：请求确认
包月/订阅类移动信息服务：
- 应事先请求用户确认；
- 未经用户确认反馈，订制不成立，不得收费；
- 请求确认信息应包含：
  - 移动信息服务企业名称；
  - 具体业务名称；
  - 资费标准；
  - 退订方式。

本案应核查是否在**开通前**清楚出现：
```text
杭州漫卷诗科技有限公司
云灵猴AI编程
20元/月
退订方式
```

### 第9项：完整订购关系
应保存：
- 用户申请订购；
- 基础电信企业请求确认；
- 用户确认反馈；
- 发送接收时间；
- 电话号码/服务接入代码；
- **具体信息内容**。

因此：
> **一个验证码数字 ≠ 完整订购关系。**

### 第10项：关系缺失/不完整
未按规定提醒、确认，或者订购关系缺失、不完整时，应按规定核查和处理相关收费争议。

官方来源：  
https://cqca.miit.gov.cn/zwgk/xyjd/fwjd/art/2020/art_2bb3623c8b924216b74a1ab22f3772d5.html

## 六、完整订购关系应由多组证据共同构成

| 节点 | 应证明什么 | 主要依据 |
|---|---|---|
| 宣传/订购入口 | 消费者事前看到的服务、价格、收费方式 | 电信服务规范6.1/6.2、574号第3/5项、消保法 |
| 用户申请订购 | 谁、何时、通过什么渠道发起 | 574号第9项 |
| 移动请求确认 | 开通前移动明确确认了什么 | 574号第5/9项 |
| 用户确认反馈 | 用户具体同意了什么 | 574号第5/9项 |
| SP向移动提供知情自愿证明 | 移动代收费前已有何种依据 | 82号第4项 |
| 正式开通与代收费 | 订单、SP、业务代码、开通、计费 | 574号第4/9项、82号 |
| 持续收费/自动展期 | 持续收费或续展的告知依据 | 消保法实施条例等 |

## 七、权利边界

### 消费者可合理要求
- 能证明完整订购关系的可读记录；
- 与本人号码有关的确认、订单、开通、计费个人信息；
- SP名称、业务名称、业务代码/接入信息、资费；
- SP许可证基本信息及有效状态；
- 与本笔订单直接相关的广告/落地页或等效可核验内容；
- 无法提供时说明原因。

### 不当然有权索取
- 运营商数据库整表；
- 风控算法/安全字段；
- 全部SP准入卷宗；
- 内部法务意见；
- 合作合同全文、分成比例；
- 整个广告账号全部历史素材；
- 与本人无关的第三方个人信息。

原则是：
> **“保存/核查义务”不等于“开放后台数据库”，但“内部数据”也不能成为拒绝提供本人相关订购信息的万能理由。**

## 八、《消费者权益保护法实施条例》第十条——自动展期/自动续费

《中华人民共和国消费者权益保护法实施条例》第十条规定：

- 经营者应以显著方式标明服务项目、内容、价格和计价方法等信息；
- 采取自动展期、自动续费等方式提供服务的，应当在**消费者接受服务前**和**自动展期、自动续费等日期前**，以显著方式提请消费者注意。

### 对本案的直接意义

2026年1月22日“已成功开通”短信载明：
- 有效期36个月；
- 如双方在有效期届满前无异议，则自动续展；
- 每次续展36个月。

因此应重点核查：

1. 该“36个月 + 自动续展36个月”条件是否在用户接受服务**之前**已经以显著方式告知；
2. 涉案广告/落地页/订购页/验证码确认短信中是否显著展示该条款；
3. 经营者是否设置在首个36个月届满、发生自动展期前再次显著提醒的机制。

### 使用边界

当前每月20元扣费发生在首个36个月有效期内，不能把“每月20元计费”直接等同为“每月自动续费”。

本条主要针对：
> **自动展期条款本身的事前显著提示 + 届满自动展期前的再次显著提醒。**
