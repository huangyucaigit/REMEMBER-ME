# 电信增值业务不明扣费：可复用维权流程

## 阶段0：先保存证据
保存：
- 账单/详单；
- 已成功开通短信；
- 开通前确认短信（如有）；
- 工单号；
- SP名称；
- 通话录音；
- 退款/充值记录；
- 监管受理编号。

争议发生后提出：
> 请在纠纷解决前保全与本人订购、确认、开通、计费、投诉有关的原始资料。

依据：《电信服务规范》第14条。

## 阶段1：运营商正式投诉

不要只问“为什么扣钱”。

固定问：
1. SP企业全称；
2. 服务接入代码；
3. 业务代码；
4. 首次申请订购；
5. 开通前请求确认完整内容；
6. 本人确认反馈；
7. 验证码对应什么业务/订单；
8. SP在首次代理收费前向运营商提交了什么“知情、自愿”证明；
9. 开通时间；
10. 持续收费依据；
11. 逐笔计费记录。

核心句：
> **请不要只证明验证码被验证过，请证明验证码验证时本人已经被明确告知并确认了具体收费业务。**

## 阶段2：区分运营商资料和SP资料

### 运营商重点
- 请求确认；
- 用户反馈；
- 开通；
- 计费；
- SP/业务代码；
- 代理收费关系；
- SP收费前“知情、自愿”证明；
- SP接入资质核验。

### SP重点
- 广告/落地页；
- 合同；
- 产品；
- 服务入口；
- 账号；
- 履行记录；
- 计费原始数据；
- SP许可证基本信息；
- 品牌授权。

双方互推时：
> 《电信服务规范》6.9要求首问负责、共同处理、不得互相推诿。

## 阶段3：电信用户申诉
适用：
- 已向运营商投诉；
- 对结果不满意；
- 或超过规定期限未有效答复。

目标：
- 核查订购确认；
- 核查代理收费；
- 核查实际SP；
- 处理具体用户争议。

## 阶段4：市场监管投诉/举报

### 对运营商
关注：
- 交易信息披露；
- 账单名称与真实服务；
- 持续收费条件；
- 消费者知情权。

### 对SP
关注：
- 实际经营主体；
- 广告/落地页；
- 合同；
- 产品和服务是否真实交付；
- 收费与持续收费；
- 经营主体信息披露。

### 对品牌方
关注：
- 是否授权；
- 合作关系；
- 不在证据不足时直接指控商标侵权。

## 阶段5：何时升级为“电信领域违法行为举报”
建议在出现以下任一事实后：
- 运营商正式确认无法提供完整订购关系；
- 监管认定订购关系缺失/不完整；
- SP许可证或接入关系出现重大异常；
- 同一业务模式可能涉及批量用户；
- 企业与运营商对关键事实互相矛盾。

举报目标：
> 调查是否存在系统性违法行为，并依法判断是否达到行政处罚立案标准。

## 阶段6：退款/和解
- 退款 ≠ 违法自认；
- 退款 ≠ 完整订购证据；
- 没有明确终局和解协议，不宜把“费用已退”写成“全部争议已解决”；
- 高于法定赔偿标准的民事和解可以协商，但不要以停止举报作为主动索取高额补偿的威胁。

## 最短六问
1. 谁提供？
2. 买什么？
3. 多少钱、怎么持续收费？
4. 我怎么明确确认的？
5. 运营商代收费前拿到了什么“知情、自愿”证明？
6. 9个月到底交付了什么服务？
