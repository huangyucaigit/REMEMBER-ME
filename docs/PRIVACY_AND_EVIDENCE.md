# 公开仓库隐私与证据管理

本仓库公开。**保护隐私优先于把所有证据上传。**

## 不公开
- 完整手机号；
- 身份证；
- 家庭住址；
- 银行卡；
- 验证码；
- 未脱敏原始录音；
- 无关第三方个人信息；
- 登录密钥。

## 原件与公开版分离

```text
本地私有证据库
├── 原始截图
├── 原始录音
├── 完整短信
├── 原始PDF/Word
└── 完整交易记录

GitHub公开仓库
├── 脱敏截图
├── 证据索引
├── 脱敏文字稿
├── 法规
└── 监管处理结果（脱敏）
```

## 原始文件哈希

建议计算 SHA-256 文件哈希，公开记录哈希值而不公开原件。

Windows PowerShell：
```powershell
Get-FileHash .\evidence-original.m4a -Algorithm SHA256
```

## 通话录音入库
每通录音建立：
- 证据编号；
- 日期时间；
- 号码（脱敏）；
- 对方自称身份；
- 关键原话时间点；
- 已确认事实；
- 对方主张；
- 拒绝/未回答事项；
- 与其他证据是否矛盾；
- 原始文件SHA-256。

## 公开表述分级
- **已确认**
- **企业主张**
- **公开线索**
- **待核实**

监管正式认定前，避免将“涉嫌/争议”写成“已经违法/诈骗”。
