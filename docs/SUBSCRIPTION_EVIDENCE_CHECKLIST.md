# 完整订购及代理收费证据链核查清单

核心原则：

> **不要只问“有没有验证码”，要问“验证码在什么明确告知内容下，确认了哪一项具体收费业务”。**

## 一、七个核心节点

### 1. 宣传/订购入口
问杭州漫卷诗：
- “快捷换图标大师”广告是谁投放；
- 与本笔订单对应的广告素材/落地页；
- 获取验证码前页面显示什么；
- 是否清楚出现真实服务商、业务名称、20元/月、持续收费及退订方式。

### 2. 用户申请订购
问浙江移动：
- 首次申请时间；
- 谁发起；
- 渠道；
- SP代码；
- 业务代码；
- 服务接入代码；
- 原始订购请求具体内容。

### 3. 浙江移动请求确认
重点索要：
- 成功开通前的请求确认完整原文；
- 发送时间；
- 发送端口；
- 是否包含：
  - 杭州漫卷诗科技有限公司；
  - 云灵猴AI编程；
  - 20元/月；
  - 退订方式。

依据：574号第5项。

### 4. 用户确认反馈
重点核查：
- 确认时间；
- 确认方式；
- 具体反馈内容；
- 验证码提交/校验；
- 验证码对应订单号/业务代码；
- 验证码是否只是普通手机号验证。

依据：574号第5、9项。

### 5. SP向移动提供“知情、自愿”证明
这是代理收费链的新增关键节点。

问浙江移动：
> 杭州漫卷诗在浙江移动首次向我代收20元之前，依据信部电〔2005〕82号第4项，向浙江移动提交了什么资料，用于证明我是“知情、自愿”使用该业务？

要求说明：
- 是否存在；
- 类型；
- 形成时间；
- 对应业务；
- 能证明的具体内容。

### 6. 正式开通与代理收费
核查：
- 订单/流水号；
- 开通时间；
- SP；
- SP代码；
- 业务代码；
- 资费；
- 逐笔收费；
- “和教育”与“云灵猴AI编程”的关系。

### 7. 持续收费与服务履行
问：
- 一次所谓确认为什么能产生持续包月；
- 哪条协议/页面明确了持续收费；
- 20元/月到底购买什么；
- 服务入口、账号；
- 9个月实际使用/交付记录。

## 二、电话时最短的六问

1. **开通前完整请求确认信息在哪里？**
2. **哪里明确写了SP、云灵猴AI编程、20元/月、退订方式？**
3. **我的确认反馈原始记录在哪里？**
4. **验证码到底绑定什么订单和具体收费业务？**
5. **杭州漫卷诗在移动第一次代收费前提供了什么“知情、自愿”证明？**
6. **9个月里到底向我交付了什么服务？**

## 三、对方常见回复与回应

| 对方说法 | 回应 |
|---|---|
| “系统里有验证码” | 请提供验证码对应的完整确认内容、具体订单、业务代码及用户确认反馈。 |
| “已经给你充180元” | 争议费用处理不替代订购真实性核查，请继续回答完整订购关系。 |
| “订购凭证找厂家” | 移动应回答自身掌握的请求确认、用户反馈、开通、计费；SP应提供广告/合同/服务资料，双方不得互推。 |
| “订购凭证找移动” | SP应回答广告、落地页、合同、服务交付、计费原始数据及其向移动提交的知情自愿证明。 |
| “这是内部数据不能提供” | 对与本人号码直接相关的信息，可依法查阅/复制；可脱敏安全字段，但请不要整项拒绝。 |
| “只能告诉你验证码” | 验证码数字不能替代574号第9项所要求的完整订购关系。 |
| “不能提供” | 请在工单/书面答复中逐项记录“无法提供/无记录”及具体理由。 |
