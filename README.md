# REMEMBER-ME

一个面向消费者的**电信增值业务扣费维权跟踪与方法仓库**。

本仓库从一宗真实的“云灵猴AI编程”增值业务扣费争议出发，目标不是只解决一笔 180 元费用，而是把**事实、证据、法规、投诉路径、监管反馈和可复用模板**系统整理出来，供遇到类似“不明订阅 / 话费代扣 / SP 增值业务 / 验证码订购争议”的消费者参考。

> **仓库原则**
>
> 1. **事实与判断分开**：只有有截图、录音、官方查询或企业明确回复支持的内容才写成“已确认事实”。
> 2. **不预判违法结论**：监管机关正式认定前，统一使用“争议”“涉嫌”“待核实”等表述。
> 3. **保护隐私**：公开仓库不上传未脱敏手机号、身份证、完整录音、验证码等个人信息。
> 4. **可复核**：每一项重要主张尽量对应证据编号或官方法规来源。
> 5. **可复用**：把本案沉淀为其他消费者也能使用的清单、模板和流程。

## 本仓库不做什么

- 不公开个人未脱敏信息；
- 不把尚未核实的线索写成违法事实；
- 不鼓励以举报、曝光作为索取高额补偿的交易筹码；
- 不替代律师、监管机关或法院的正式法律判断。

## 给遇到类似情况的人

如果你遇到类似“不明订阅/话费代扣”，先保存：
- 账单/详单；
- 开通成功短信；
- 开通前确认短信（如有）；
- 运营商工单号；
- SP 名称、业务代码、服务接入代码；
- 通话时间与录音；
- 退款/充值主体、金额及备注；
- 监管平台受理编号。

再按本仓库的 [行动手册](docs/ACTION_PLAYBOOK.md) 逐步处理。
